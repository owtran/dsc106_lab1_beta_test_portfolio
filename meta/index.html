We are basically making a dashboard with a scatter plot representing the commits we did in GitHub for our project and each dot shows the date, author, and number of lines for the commit! Some of the functionality include hovering over a dot to see the commit details, dragging a box to selecting the commits together, and showing the # of languages for all of the commits
